# .gitignore

Adapted from `unified_broker_interface/.gitignore`, with the tier-specific entries removed because this project has no `.env.dev`, `.env.uat`, or `.env.prod`.

This file was written before `.env` was created, deliberately, so that the file holding the database credentials was never present in an untracked and unignored state. The project is not yet a git repository, but is expected to become one.

The entries fall into five groups, marked in the file with section headers: Python build artifacts and virtual environments, the environment file holding secrets, Claude Code local state, editor files, and operating system files.

Those section headers are the one place a comment is kept in a config file, at the user's explicit request. They label groups of entries rather than explain reasoning, so they do not create the clutter the no-comments rule exists to prevent.
